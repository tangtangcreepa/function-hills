# 函数丘陵（Function Hills）

> 三维函数世界 —— 进入由数学函数生成的世界自由探索。

一款运行于 Windows 的桌面软件。玩家进入一个由数学函数 / 方程实时生成的三维世界，既能以自由飞行的方式观察（**编辑模式**），也能受重力约束、站到函数图像上行走探索（**探索模式**）。

## 功能特性

- **三种函数输入形式**，实时生成三维图像
  - 显式函数 `z = f(x, y)`
  - 隐函数方程 `f(x, y, z) = 0`
  - 参数方程 `(x, y, z) = F(u, v)`
- **内置常见函数 / 方程预设**，一键填入
- **输入历史记录**：自动保存，可点击回填，重启后保留
- **双模式自由切换**
  - 编辑模式：自由飞行视角；默认关闭天空 / 雾场 / 光照，可开启「预览」并调整环境参数
  - 探索模式：第一人称、受重力约束；函数图像变为略粗糙的刚体，可承载玩家站立行走；渲染天空、雾场与光照
- **坠落保护**：探索模式下低于阈值自动传送回世界原点
- **存档导入 / 导出**：支持备份为 JSON 文件并在其他机器恢复
- 界面简洁，淡灰色主题，全中文

## 环境要求

- Windows 10 / 11
- [Node.js](https://nodejs.org/) 18 及以上（开发与构建）

## 快速开始

```bash
# 安装依赖
npm install

# 构建并启动（开发运行）
npm start

# 打包为免安装单文件 exe，产物在 release/ 目录
npm run dist
```

`npm run dist` 使用 electron-builder 打包为 portable 目标的 `函数丘陵.exe`，双击即可运行，无需安装。

## 操作说明

| 按键 | 编辑模式 | 探索模式 |
|---|---|---|
| `W` / `A` / `S` / `D` | 前后左右（水平方向） | 前后左右（水平方向） |
| `空格` | 向上 | 跳跃 |
| `左 Shift` | 向下 | 下蹲 |
| 鼠标移动 | 转视角 | 转视角 |
| `Esc` | 退出指针锁定 | 退出指针锁定 |

- 点击左侧栏「编辑模式 / 探索模式」按钮自由切换。
- 点击左侧栏「生成函数」按钮打开函数编辑页。

## 技术栈

| 用途 | 依赖 |
|---|---|
| 桌面容器 | [Electron](https://www.electronjs.org/) |
| 三维渲染 | [Three.js](https://threejs.org/) |
| 物理模拟 | [@dimforge/rapier3d-compat](https://rapier.rs/) |
| 表达式解析 | [mathjs](https://mathjs.org/) |
| 等值面生成 | [isosurface](https://github.com/mikolalysenko/isosurface) |
| 打包 | esbuild + electron-builder |
