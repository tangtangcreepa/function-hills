## 四、关键实现参考（避免新会话重复踩坑）

### 目录与构建
- 源码在 `src/`；`release/` 只是打包产物。入口 `src/main.js`，构建产物 `src/dist/bundle.js`（ESM）+ `implicit.worker.txt`（IIFE，被当文本内联进 bundle）。
- `npm run build` = 两条 esbuild；`package.json` 的 `build.win.artifactName` 当前为 `函数丘陵.exe`；版本号在 `package.json` 的 `version` 与 `electron/preload.js` 的 `appInfo.version`（两处需同步，界面版本角标读 `window.appInfo.version`）。
- 打包命令（防 GitHub 超时 + 关掉 ELECTRON_RUN_AS_NODE）：
  `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ env -u ELECTRON_RUN_AS_NODE npx electron-builder --win portable`
- **Windows Defender 锁文件**：打包时若旧 `函数丘陵.exe` 被 MsMpEng.exe 占用会卡「waiting for unlock」。临时改 artifactName 绕开，之后删除旧文件再改回。
- Electron 冒烟脚本：v1.0 起一次性 `.smoke-v*.js` 已删除，后续按阶段临时创建、验后即删（勿留在仓库）。要点：隐藏 BrowserWindow 会节流 rAF（物理需 `show:true` 或手动推进）；运行需 `env -u ELECTRON_RUN_AS_NODE`；executeJavaScript 结尾加 `void 0;` 避免「An object could not be cloned」。

### 字段命名陷阱（关卡系统）
- 出生点叫 **`start`**（不是 spawn）；终点叫 **`end`**（不是 endpoint）；跑酷元件叫 **`props`**；HUD 元素 id 是 **`#play-hud`**（不是 #hud）。
- 内置关字段：`id / name / desc / start / fallY / surfaces / props / treasures / end`，可选 `checkpoints`；`surfaces[]` 里可选 `adjustable / hint / params / properties / origin / range / ranges / friction`。
- 内置关与自制关数据结构同构，`enterLevel` 走同一套逻辑。

### localStorage key 清单（统一前缀 `function-hills-`）
`-fly-speed`、`-keymap`、`-sidebar-width`、`-sidebar-collapsed`、`-panel-collapsed`、`-levels-complete`（已完成关卡 id 数组）、`-custom-levels`（自制关数组）、`-collection`（已收集常数）、`-env-defaults`、`-history`、`-save-index`/`-save-<id>`/`-active-save`。读取惯例：`JSON.parse(localStorage.getItem(KEY) || '[]')` + `Array.isArray` 兜底 + try/catch。

### 复用入口
- 生成函数：`main.js` 的 `generate(type, expr, ranges, origin, range)`（约 488 行），内部 parseFunction → buildGeometryAsync → `addSurface`。一键生成/预设回填都调它。
- 新增图像必经 `addSurface`（约 518 行）——生成类成就统计点。
- 关卡运行时 `playSession.js`：`start` 有 `session.startedAt = performance.now()`；`win()` 算 `elapsed` 秒并经 `onWin({time,count,total})` 传出。
- 关卡回调（`main.js` enterLevel 内，约 1524-1546）：`onCollect` / `onProgress` / `onAllCollected` / `onCheckpoint` / `onWin` —— 成就与计时判定集中点。
- 模式切换广播：`src/mode.js` 的 `onModeChange(fn)`；main.js 已注册于约 773 行。
- 存储模板：`collection.js`（Set + JSON + 去重返回 boolean）与 `markLevelComplete`（id 数组）。

### 新增侧边栏面板样板
1. `index.html` `#sidebar-body` 内加 `<section id="xxx-panel" class="panel [hidden]"><h2>标题</h2>…</section>`；内容用 `<label class="row">` 横排、`<h3>` 分组、`.hint` 说明、`.btn`/`.btn-primary` 按钮。
2. 手风琴折叠自动生效（main.js 约 859-884 对 `#sidebar .panel` 且含 `>h2` 的统一处理），无需额外代码。
3. 若关卡模式要隐藏，在 `style.css` 的 `#sidebar.level-mode …` 块（约 223-233）追加选择器。
4. JS：新建 `src/ui/xxxPanel.js` 导出 `initXxxPanel({onXxx})`，返回 API；`main.js` import + DOM 引用 + 实例化（UI 初始化区约 1057-1113）+ 打开按钮 `classList.toggle('hidden')` + 打开时 render。
5. 样式类惯例：面板底 `#ececec`、输入白底 `#ffffff`、边框 `#d0d0d0`、强调蓝 `#7a9ec4`、危险红 `#c0392b`；列表参考 `.fn-list`/`.codex-list`/`.save-list`。

### 已知性能瓶颈（v19 用）
隐式标量场求值（res=96 约 265 万格点 × mathjs）最重；参数/原点滑杆触发全量几何重建 + `rebuildColliders()` 全量 trimesh 重建；`computeVertexNormals` 每次构建重算；体积云 raymarch / UnrealBloom / 2048² 阴影（默认关）。已有优化：Worker + transferable + genId 过期丢弃 + 预计算场 + 各滑杆防抖 + 碰撞体增量更新 + 摩擦只改系数。

## 五、每阶段通用验收方法

1. `npm run build` 通过。
2. Electron 冒烟（临时创建 `.smoke-v*.js`，`env -u ELECTRON_RUN_AS_NODE`），断言本阶段验收点 + 收集 `console.error` 判零报错，验后删除脚本。
3. 阶段末更新 `开发日志/` 当日文件（完成事项 + 待办事项 + 备注），停下向用户确认再继续。
4. 全部完成后：版本号递增（`package.json` 与 `preload.js` 两处同步）、记入 `docs/07-版本历史.md`、打包 `release/函数丘陵.exe` 供实机验收。
