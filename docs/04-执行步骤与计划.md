# 04 · 执行步骤与计划

> 小步推进：一次只做一个阶段，每阶段完成跑通验收点、更新开发日志后，停下向用户确认再继续。

## 阶段 0 · 文档脚手架 ✅
- 创建 CLAUDE.md、docs/ 五个标准文件、开发日志/ 模板与今日日志；设置每日日志提醒。
- 验收：文件齐全可读，指引正确，模板可用。

## 阶段 1 · 空窗口能跑
- 用 winget 安装 Node.js LTS；`npm init`；搭 Electron 骨架（main.js / preload.js / index.html）。
- 验收：`npm start` 弹出空白窗口。

## 阶段 2 · 3D 画布 + 编辑模式自由相机 + 侧边栏
- Three.js 场景（地面/坐标轴参考）；自由飞行相机（WASD + 空格上/Shift下 + 鼠标）；淡灰左侧栏（「生成函数」按钮 + 模式切换占位）。
- 验收：能飞行、看到空世界、UI 布局正常。

## 阶段 3 · 函数管线（先做显式 z=f(x,y)）
- parser + geometry（显式）+ 预设 + 历史 + 函数编辑面板。
- 验收：输入或选预设 → 生成图像；历史可回填、重启保留。

## 阶段 4 · 隐式 + 参数方程
- isosurface 隐式网格、参数曲面。
- 验收：球、圆环面、莫比乌斯带等正确生成。

## 阶段 5 · 环境系统
- 天空/雾/光照；编辑模式「预览」开关 + 参数滑杆。
- 验收：编辑模式默认无环境，开预览可见，滑杆实时生效。

## 阶段 6 · 探索模式 + 物理
- Rapier 世界、图像 trimesh 刚体、角色控制器、跳跃/下蹲、坠落传送、两模式切换。
- 验收：站在图像上走/跳/蹲，掉出边界自动回原点，两模式自由切换。

## 阶段 7 · 联调 + 打包 .exe
- 全流程回归测试；electron-builder 产出 portable `函数丘陵.exe`。
- 验收：双击 exe 完整跑通所有验收点。
