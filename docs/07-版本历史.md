# 07 · 版本历史

> 每个正式发布版本一条记录：版本号 / 日期 / 变更要点。后续更新沿用 semver 递增（`package.json` 的 `version` 与 `electron/preload.js` 的 `appInfo.version` 两处同步）。

## v1.1.2 · 2026-10-19 · 高画质掉帧回归修复 + 下坠阈值对齐

- 修复：高画质不再放大渲染分辨率。v1.1.0「画质档」高档把像素比设为 `min(dpr,2)`，把 v1.0.0 已通过 `setPixelRatio(1)`（不跟随系统缩放）修好的满屏逐像素开销（尤其体积云 raymarch）在高分屏上放回 4 倍；现像素比固定回 1。
- 现象解释：隐式预设（球/圆锥/圆环）是悬浮立体，面对时背景几乎全是天空=体积云跑满屏，故「只面对隐式掉帧、面对显式/参数不卡」；显式/参数铺地、云几乎不跑，不受影响。
- 调整：下坠判定阈值由固定 -16.7 改为 `-3×视距`（对齐隐式曲面竖直范围 Vz=3×视距），避免大视距下站在隐式曲面底部被误判坠落。

## v1.1.1 · 2026-10-19 · 性能修复 + 云影/视距降本

- 修复：画质档位不再于启动时覆盖「云采样」。此前 `applyQuality` 启动末尾无条件把云采样写回 14，覆盖用户手动调低并保存的值（体积云 raymarch 步数 +75%），导致「云+阴影+辉光+体积雾」全开时明显卡顿；现在云采样只由环境面板唯一控制。
- 性能：云影降本（256²→128²、穿透积分 20→12 步，视觉几乎无差）；「视距」拖动重建参考网格加 250ms 防抖（消除 `new GridHelper` 分配抖动）。
- 清理：移除 `applyQuality` 处过时注释，避免日后照注释重蹈覆辙。

## v1.1.0 · 2026-10-18 · 人性化体验 + 性能优化（v20）

- 舒适度与反馈：设置面板（鼠标灵敏度 / FOV / 视角平滑 / 头部晃动 / 飞行速度）；碰撞体积修正（眼高 1.6→0.7）；toast 自动消失渐隐；冲刺反馈；破坏性操作二次确认；按键重绑冲突检测；材质「保存为默认」。
- 函数/参数输入：自建表达式编辑器（语法高亮 + 括号匹配 + 自动补全 + 实时校验）；参数定义编辑器（初值/范围/步长/标签/锁定）；滑杆精调（Shift 细调 + 步进按钮）；预设分组搜索；历史含参数定义；非阻塞错误徽章；共享滑杆行组件。
- UI 灵动化：面板/浮层/卡片统一淡入淡出过渡（`transitions.js`），尊重 `prefers-reduced-motion`。
- 性能优化：画质档位（低/中/高：像素比、阴影贴图、云采样分级）；enterLevel 免二次重建；GridHelper 内存泄漏修复；后期处理懒初始化。

## v1.0.0 · 2026-10-16 · 首个正式版

- 核心：进入由数学函数生成的三维世界；编辑模式自由飞行、探索模式受重力行走、关卡模式（4 个内置关 + 自制关上传）。
- 编辑器：显式 / 隐式 / 参数方程三种函数；预设 + 历史 + 参数范围/锁定 + 原点偏移 + 独立图像范围 + 摩擦属性。
- 探索：Rapier 角色控制器 + 手动动量模型（惯性、摩擦手感、坡面重力、下坡限速）、跳跃/下蹲/冲刺、第一人称相机晃动。
- 环境：天空/雾/光照/积云/日落过渡/昼夜；多槽自动存档 + 备份导出/导入。
- 关卡（v15）：4 个内置关 + 竞速计时 + 最快纪录持久化。
- 成就（v16）：10 项里程碑 + 面板 + 即时解锁提示。
- 图鉴（v17）：函数图鉴 22 预设 · 4 分类 · 一键生成。
- 输入体验（v18）：公式实时校验 + 中文错误提示 + 参数检测（不阻塞提交）。
- 性能（v19）：隐式 Worker 后台生成 + 碰撞体增量更新 + 摩擦只改系数。
- 打包：portable 单文件 `release/函数丘陵.exe`；版本号 1.0.0，界面侧栏显示版本角标。
