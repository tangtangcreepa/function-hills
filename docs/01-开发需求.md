# 01 · 开发需求

## 项目概述
一款运行于 Windows 的桌面软件「函数丘陵」。玩家进入一个由数学函数/方程生成的三维世界，可自由飞行观察（编辑模式），也可受重力约束、站到函数图像上行走探索（探索模式）。

## 核心玩法
- 玩家出生在世界原点 (0, 0, 0)。
- 水平移动：`WASD` = 前后左右（相对世界水平方向）。
- 垂直：编辑模式下 `空格` = 向上、`左Shift` = 向下；探索模式下 `空格` = 跳跃、`左Shift` = 下蹲。

## 生成函数
- 窗口左侧有「生成函数」按钮，点击弹出编辑页面。
- 玩家输入函数，支持三种形式：
  1. 显式函数 `z = f(x, y)`
  2. 隐函数方程 `f(x, y, z) = 0`
  3. 参数方程 `(x, y, z) = F(u, v)`
- 世界根据输入生成对应三维图像。
- 编辑页内置常见函数/方程预设。
- 保存玩家历史输入记录（可点击回填、重启后保留）。

## 两种世界模式（可自由切换）

### 编辑模式
- 自由视角（飞行）。
- 默认不渲染天空、雾场、光照等环境；可开启「预览」，并调整环境参数。

### 探索模式
- 受世界重力约束（第一人称）。
- 函数图像性质变为略粗糙的刚体，可承载玩家站立/行走。
- 渲染天空、雾场、光照。
- 玩家下坠到一定高度时自动传送回世界原点。

## UI 设计
- 简洁直观。
- 主题颜色：淡灰色。
- 语言：中文。

## 非功能需求
- 稳定、安全、有效推进（小步开发，每阶段可验收）。
- 交付产物：可双击运行的 `.exe`（免安装 portable 优先）。
