# 02 · 技术方案

## 技术选型

| 用途 | 技术 | 理由 |
|---|---|---|
| 桌面外壳 / 打包 .exe | Electron + electron-builder | 纯 JS 技术栈，易搭建调试；可产出免安装 portable .exe |
| 3D 渲染 | Three.js | 成熟，几何体 / 光照 / 雾 / 天空齐全 |
| 物理引擎 | @dimforge/rapier3d-compat | WASM；自带 `KinematicCharacterController`，适合在任意网格上行走/爬坡/防穿透 |
| 表达式解析 | mathjs | 编译 x/y/z/u/v 表达式，支持 sin/cos/exp、`^` 等 |
| 隐函数网格化 | isosurface | marching cubes / surface nets 提取 f=0 等值面 |

## 模块架构

| 模块 | 路径 | 职责 |
|---|---|---|
| 主进程 | electron/main.js | 创建窗口、加载页面 |
| 桥接 | electron/preload.js | contextBridge 安全桥接 |
| 页面骨架 | src/index.html | 左侧栏 + 3D 画布 |
| UI | src/ui/*.js | 侧边栏、函数编辑面板、环境参数面板 |
| 世界 | src/world/*.js | 场景、相机（自由/第一人称）、环境（天空/雾/光照） |
| 函数 | src/functions/*.js | 解析、几何体、预设、历史 |
| 物理 | src/physics/physics.js | Rapier 世界、图像刚体、角色控制 |
| 模式 | src/mode.js | 编辑/探索状态机 |

## 数据流

```
用户输入函数
  → parser.js（mathjs 编译，类型判定）
  → geometry.js（显式网格位移 / 隐式 isosurface / 参数采样 → BufferGeometry）
  → scene.js 渲染网格；探索模式下 physics.js 生成 trimesh 刚体
```

## 关键实现要点

- **显式 z=f(x,y)**：x,y ∈ [-10,10] 网格采样，位移 z 成曲面。
- **隐式 f(x,y,z)=0**：[-10,10]³ 的 64³~96³ 网格求值，`isosurface` 提取 0 等值面并计算法线。
- **参数方程**：u,v 采样成曲面。
- **物理**：函数表面 = 静态双面 trimesh；角色 = `KinematicCharacterController` + 胶囊（行走/爬坡/防穿透/跳跃）。
- **异步生成**：大网格生成放到异步流程，UI 显示「生成中…」，避免卡顿。
