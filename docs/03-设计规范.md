# 03 · 设计规范

## UI 规范

- 主题：淡灰色。
  - 主底色 `#f5f5f5`，面板底色 `#ececec`，边框 `#d0d0d0`
  - 主文字 `#333333`，次级文字 `#666666`
- 布局：左侧固定栏宽约 280px，右侧为 3D 画布。
- 按钮：浅灰底、圆角、hover 时加深；主按钮略突出。
- 语言：全中文。

## 交互规范（按键表）

| 按键 | 编辑模式 | 探索模式 |
|---|---|---|
| W / A / S / D | 前后左右（水平） | 前后左右（水平） |
| 空格 | 向上 | 跳跃 |
| 左 Shift | 向下 | 下蹲 |
| 鼠标移动 | 转视角 | 转视角 |
| Esc | 退出指针锁定 | 退出指针锁定 |

- 鼠标采用指针锁定（Pointer Lock）控制视角。
- 模式切换：点击左侧栏「编辑模式 / 探索模式」按钮自由切换。

## 命名与目录规范

- 目录：`electron/`、`src/`（`ui/`、`world/`、`functions/`、`physics/`）。
- 文件名：小驼峰（如 `functionEditor.js`）；文档用中文名 + 序号。
- 模块职责单一，跨模块通信通过 `mode.js` 状态机与事件。

## 坠落保护

- 探索模式下，玩家 Y 坐标低于阈值（默认 -50）时，自动传送回世界原点上方。
